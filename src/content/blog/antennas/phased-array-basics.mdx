A phased array antenna achieves beam steering by exploiting constructive and destructive
interference between multiple radiating elements. Each element transmits (or receives) the
same signal, but with a controlled phase offset applied between adjacent elements.

## The Array Factor

For a uniform linear array of $N$ elements with spacing $d$ and progressive phase shift $\beta$,
the normalized array factor is:

$$AF(\theta) = \frac{1}{N} \sum_{n=0}^{N-1} e^{\,j n \psi}, \quad \psi = kd\cos\theta + \beta$$

where $k = 2\pi/\lambda$ is the wavenumber. One possible in-phase direction is the angle $\theta_0$ where $\psi = 0$, provided the arccosine argument lies in $[-1,1]$:

$$\theta_0 = \arccos\!\left(-\frac{\beta}{kd}\right)$$

Other in-phase directions satisfy $\psi = 2\pi m$ for integer $m$. More than one visible solution produces grating lobes; a steering angle is not necessarily unique.

## What to observe

**Element count $N$** — at fixed spacing and uniform weights, increasing N narrows the main lobe. It does not make relative sidelobes arbitrarily small; for large uniform arrays the first sidelobe approaches about −13.3 dB. Near broadside, for a sufficiently long array, the approximate full half-power beamwidth is $50.8° / (N \cdot d/\lambda)$. That approximation is unreliable near endfire or for electrically short arrays.

**Spacing $d > \lambda/2$** — grating lobes can appear, depending on the steering direction. These are additional in-phase beams caused by spatial sampling. Check all visible solutions of $kd\cos\theta + \beta = 2\pi m$.

**Phase shift $\beta$** — this is beam steering. Setting $\beta = -kd\cos\theta_0$ points the main lobe at $\theta_0$. At $d = \lambda/2$, interior scan directions avoid additional in-phase beams, but exact endfire has an equal beam at the opposite endpoint. Spacing strictly below half a wavelength avoids that endpoint ambiguity in this ideal model.

## Key trade-offs

| Parameter | Effect |
|---|---|
| Increase $N$ | Narrower beam at fixed spacing; more hardware; sidelobe level still depends on weights |
| Increase $d$ beyond $\lambda/2$ | Grating lobes become possible; depends on scan angle |
| Change $\beta$ | Changes visible in-phase directions; the ψ = 0 solution can leave the visible range |
